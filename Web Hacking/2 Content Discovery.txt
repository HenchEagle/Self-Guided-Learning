/robots.txt contains a list of directories that are allowed/disallowed to be crawled by search engines.

many frameworks provide default favicons which can provide information on what framework was used to create a website.
https://wiki.owasp.org/index.php/OWASP_favicon_database
this owasp list contains a large list of common framework favicons

to search the favicon within the database you need to get the md5 hash of the .ico

this can be done by curling the url that leads to the favicon and piping it into the md5sum command on Linux
curl <target_favicon_url> | md5sum

OSINT (Open-source intelligence)
Google dorking (google hacking) a way of performing more advanced searches. (site:tryhackme.com filetype:pdf inurl:login)

Wappalyzer, performs a scan of a website and returns information pertaining frameworks, versions, Content management systems +

Waybackmachine https://web.archive.org/ - contains a historical archive of websites dating to the 90s

GitHub - Git is a version control system, it allows teams to track changes made to files, commiting them to repositories with messages so that everyone knows exactly what was changed. you can search companies and websites for potentially unhidden content.

S3 Buckets - amazon aws cloud services can sometimes have incorrectly setup authorisation. the format for s3 buckets is s3.amazonaws.com you can find these types of urls through page source, GitHub repos or through automation - utilising common search terms such as {name}-assets, {name}-www, {name}-public, {name}-private.
