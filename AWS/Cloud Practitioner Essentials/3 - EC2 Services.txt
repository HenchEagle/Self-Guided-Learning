** AWS CONTAINERS **
Container Orchestrastion services provide control over the whole lifecycle of a Container, automatically scale out depending on resource demands.
They also handle recovery, monitoring and updates.

There are two main options

ECS (Elastic Container Service)
Streamlined and integrated with small configuration options like instance types and load balancers
It is a fully-managed service

EKS (Elastic Kubernetes Service)
open source, a lot of control and flexibility but more complex

ECR (Elastic Container Registry)
Fully managed docker image registry. Container Orchestration tools can leverage these images to spawn containers.

** PROVISIONING CONTAINERS **
There are 2 options to provision them

EC2 - Unmanaged container Orchestration

Fargate - serverless container orchestration

** DEPLOYING CONTAINERS **
1. Deploy images to the ECR (elastic container registry)
2. Choose an orchestration service based on needs (ECS - Small single apps with expected usage) (EKS - Larger, more complex, or high traffic applications)
3. .Select a compute platform, ec2 for more control, fargate for agility and lower maintanence.
